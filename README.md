# Projeto SIEM - Monitoramento de Servicos

## Objetivo
Automatizar a verificacao dos servicos principais do Elastic Stack.

## Servicos monitorados
- Elasticsearch
- Kibana
- Filebeat

## Tecnologias utilizadas
- Ubuntu Server 22.04.5 LTS
- Bash
- Git
- Cron
- Elastic Stack 7.17.29

## Execucao
Para executar manualmente:

./verificar_siem.sh

## Automatizacao
A verificacao pode ser agendada pelo Cron
para ocorrer a cada cinco minutos.

## Controle de versao
O codigo e a documentacao sao mantidos
em um repositorio Git local.
